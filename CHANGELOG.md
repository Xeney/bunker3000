# Changelog

## [2.0.0] - 2026-06-10

### Графический интерфейс (Fyne)

#### Добавлено
- **Полноценный GUI** на фреймворке Fyne v2.7.4
- **Главное меню**: 4 кнопки (Новая игра, Загрузить, Достижения, Выход)
- **Экран выбора сложности**: кнопки с описанием параметров
- **Экран выбора класса**: 4 класса с интерактивным описанием
- **Игровой экран**: прогресс-бары здоровья/еды/воды с цифрами, отображение дня, события с двумя кнопками выбора, результат + кнопка "Продолжить"
- **Экран Game Over**: статистика победы/поражения + список полученных достижений
- **Экран достижений**: просмотр всех достижений со статусом
- **Размер окна**: 800x600, тёмная тема по умолчанию

#### Изменено
- Полная миграция с консольного интерфейса на GUI
- `main.go` теперь содержит только 10 строк — запуск окна
- Вся логика разделена на слои:
  - `game/` — контроллер (состояние, фазы, переходы)
  - `gui/` — представление (экраны, виджеты)
  - Модели (`player/`, `events/`, `save/`, `achievements/`) — без изменений
- Удалены консольные модули `utils/` (Clear, WaitEnter, GetIntInput) и `colors/` (ANSI)
- `save.go` расширен: добавлено поле `TotalDamage` в `SaveData`

#### Технические изменения
- Добавлена зависимость `fyne.io/fyne/v2 v2.7.4`
- Новый пакет `game/` (state.go) — GamePhase, GameState, LoadFromSave
- Новый пакет `gui/` (7 файлов) — все экраны и виджеты Fyne
- Игровой цикл переведён с блокирующего `for + fmt.Scan` на событийно-управляемую модель (callback'и кнопок)
- Требуется C компилятор (GCC/MinGW) для сборки на Windows

#### Статистика
- **Модулей**: 6 (main, game, gui, player, events, save, achievements)
- **Тестов**: 23 (все проходят)
- **Размер бинарника**: ~43 MB (CGO + GLFW)

## [1.2.0] - 2026-06-10

### Полная перезагрузка

#### Добавлено
- **Уровни сложности**: Лёгкая (10 дней), Обычная (7 дней), Сложная (5 дней)
- **Классы персонажей**: Выживальщик, Медик (+здоровье, двойное лечение), Разведчик (двойные ресурсы), Боец (половина урона)
- **12 новых событий** (всего 32): колодец, засада, буря, дом, путник, пожар, подвал, костёр, тропа, машина, источник, охота
- **Категории событий**: каждая категория подсвечивается своим цветом
- **Система достижений**: 11 ачивок (ПЕРВЫЙ ШАГ, ВЕТЕРАН, ВЫЖИВАЛЬЩИК и др.)
- **Сохранение и загрузка**: JSON-сериализация в `bunker3000_save.json`
- **Главное меню**: новая игра, загрузить, достижения, выход
- **Цветной интерфейс**: ANSI escape codes, поддержка Windows VT

#### Изменено
- Все эмодзи заменены на текстовые теги `[РЕСУРСЫ]`, `[БИТВА]` и т.д.
- Формат вывода статуса: рамки `+---+` вместо эмодзи-боксов
- Полностью переработан игровой цикл (экран результата -> статус -> Enter -> следующий день)
- `CreatePlayer` теперь принимает параметры сложности и класса
- Ресурсные константы вынесены в конфиг сложности (`DifficultyConfig`)

#### Исправлено
- **Off-by-one в финальной статистике**: "6 из 7" -> "7 из 7" при победе
- **`WaitEnter()` не ждал Enter**: `fmt.Scan` оставлял `\n` в буфере, `reader.ReadString` читал его мгновенно
- **int8 overflow в ChangeHealth**: `Health=100 + amount=30` переполнялось до `-126`
- **Scout удваивал отрицательные значения**: добавлена проверка `amount > 0`
- **AddEat/AddWater не защищали от отрицательных значений**: добавлен нижний предел 0
- **Некорректный день при смерти от истощения**: день смерти отображался как `ThisDay-1`

#### Технические изменения
- `ThisDay` больше не инкрементируется в `StartNewDay()` — перенесено в `main.go` после экрана результата
- Добавлен модуль `colors/` (ANSI-цвета, включение VT-режима на Windows)
- Добавлен модуль `save/` (JSON-сохранение)
- Добавлен модуль `achievements/` (трекер достижений)
- Поле `Category` в структуре `Event` для цветовой группировки
- Все тесты обновлены под новое API

#### Статистика
- **Событий всего**: 32 (+60%)
- **Тестов**: 23
- **Модулей**: 6 (main, player, events, utils, save, achievements, colors)

## [1.1.0] - 2026-06-09

### Добавлено — 20+ событий

#### Ресурсные события (4)
- Ручей с водой — пополнение воды
- Ягодная поляна — сбор еды
- Заброшенный склад — много консервов
- Дождь — сбор дождевой воды

#### Боевые события (3)
- Нападение бродяги — бой или потеря ресурсов
- Волчья стая — серьёзное испытание
- Охотничья ловушка — рискованная добыча

#### Социальные события (2)
- Загадочный странник — помощь или обмен
- Торговец — выгодная сделка

#### Погодные события (3)
- Аномальная жара — проверка на выносливость
- Густой туман — находки или потеря времени
- Землетрясение — опасное природное явление

#### События с рандомизацией (4)
- Ядовитые грибы — 30% шанс отравления
- Рыбалка — 60% шанс удачи
- Дикий мёд — 50% шанс атаки пчёл
- Старая карта — поиск тайника

#### Полезные находки (4)
- Аптечка — восстановление здоровья
- Заброшенный рюкзак — ценные припасы
- Посёлок выживших — отдых и ресурсы
- Тайник по карте — большая удача

### Улучшения
- Добавлены эмодзи для лучшего восприятия событий
- Улучшен баланс награды и риска
- Рандомизация результатов для некоторых событий
- Расширены варианты выбора в событиях

### Технические изменения
- Обновлён генератор случайных чисел (seed)
- Добавлены новые проверки граничных значений
- Улучшена система валидации событий

### Исправлено
- Исправлена проблема с переполнением int8 в тестах
- Оптимизирована система потребления ресурсов

### Изменения баланса
- Увеличен пул событий для разнообразия
- Снижена предсказуемость исходов
- Добавлены более рискованные, но наградные варианты
