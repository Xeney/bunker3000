# Бункер-3000 — Симулятор выживания

[![Go Version](https://img.shields.io/badge/Go-1.26+-00ADD8?style=flat&logo=go)](https://go.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/Tests-27_Passing-brightgreen)](.)

Терминальная игра-симулятор выживания в постапокалиптическом мире. Управляйте ресурсами, принимайте решения и держитесь до конца.

## Версия 2.5.0 — "Терминальная эра"

- **Терминальный интерфейс** (Bubble Tea + lipgloss), зелёный на чёрном
- **238 уникальных событий** с цветовой категоризацией (ресурсы, битвы, погода, опасности, помощь, находки)
- **4 уровня сложности**, включая бесконечный режим
- **7 классов персонажей** (Выживальщик, Медик, Разведчик, Боец, Грузчик, Механик, Торговец)
- **Система кармы** (−100..+100), влияет на взвешивание событий
- **Система прокачки** (10 уровней, XP за дни/выборы/цепочки, +1 макс. ресурс и +5 HP за уровень)
- **15 достижений** для отслеживания прогресса
- **Руководство** на 10 страниц со всеми механиками
- Сохранение и загрузка игры (JSON)
- 238 событий, никаких повторов за партию

## Как играть

### Главное меню

При запуске открывается терминальное меню (зелёный на чёрном, двойные рамки):

- **Новая игра** — начать новое прохождение
- **Загрузить** — продолжить сохранённую игру
- **Достижения** — просмотр полученных достижений
- **Руководство** — подробное описание всех механик (10 страниц)
- **Выход** — закрыть игру

### 1. Выбор сложности

| Параметр | Лёгкая | Обычная | Сложная | Бесконечный |
|----------|--------|---------|---------|-------------|
| Дней до победы | 10 | 7 | 5 | ∞ |
| Расход еды в день | 1 | 1 | 2 | 1 |
| Расход воды в день | 1 | 2 | 3 | 2 |
| Стартовая еда | 15 | 10 | 5 | 10 |
| Стартовая вода | 15 | 10 | 5 | 10 |
| Макс. ресурс | 25 | 20 | 15 | 20 |
| Урон от голода/жажды | 10 | 20 | 30 | 20 |

### 2. Выбор класса

| Класс | Бонус |
|-------|-------|
| **Выживальщик** | Сбалансированный, без бонусов |
| **Медик** | +20 HP, двойное лечение |
| **Разведчик** | Двойная добыча ресурсов |
| **Боец** | Половина входящего урона |
| **Грузчик** | +6 к вместимости, +2 еды/воды на старте |
| **Механик** | +15 HP, −25% урона |
| **Торговец** | +2 еды/воды из событий помощи |

### 3. Игровой процесс

1. Игровой экран: панель статуса (здоровье, еда, вода, уровень, день, сложность, класс)
2. Случайное событие — текст с цветовой меткой категории + два варианта выбора
3. Нажмите `1` или `2` для выбора
4. Результат, начисление XP, проверка уровня
5. `Enter` — следующий день
6. Цель — продержаться все дни (зависит от сложности)

### Система кармы

- Карма меняется от каждого выбора (−100..+100)
- **+30 и выше**: чаще выпадают ресурсы, помощь, находки
- **−30 и ниже**: чаще битвы и опасности
- Итоговое описание в эпилоге

### Прокачка

- **+5 XP** за прожитый день
- **+3 XP** за добрый поступок
- **+15 XP** за цепочку событий
- **+10 XP** за победу
- Каждый уровень: **+1 макс. ресурс**, **+5 HP**
- Максимум: 10 уровень

## Установка и запуск

### Требования

- **Go 1.21+**

### Запуск

```bash
go run .
```

### Сборка

```bash
go build -o bunker3000.exe .
./bunker3000.exe
```

## Сохранение и загрузка

- Игра сохраняется после каждого дня в `bunker3000_save.json`
- Загрузка через кнопку "Загрузить" в главном меню
- Сохранение удаляется при завершении игры
- Достижения хранятся в `bunker3000_achievements.json`

## Тестирование

```bash
# Все тесты
go test -v ./...

# Только тесты событий
go test -v ./events

# Только тесты игрока
go test -v ./player
```
