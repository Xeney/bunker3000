# Бункер-3000 — Симулятор выживания

[![Go Version](https://img.shields.io/badge/Go-1.26+-00ADD8?style=flat&logo=go)](https://go.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/Tests-23_Passing-brightgreen)](.)

Графическая игра-симулятор выживания в постапокалиптическом мире. Управляйте ресурсами, принимайте решения в случайных событиях и продержитесь до конца, несмотря на голод, жару, бандитов и дикую природу.

## Версия 2.0.0 — "Графический интерфейс"

- **Полноценный GUI** на Fyne v2.7.4 (окно 800x600, тёмная тема)
- 32 уникальных события с категориями (ресурсы, битвы, погода, опасности, помощь, находки)
- 3 уровня сложности с разными параметрами
- 4 класса персонажей с уникальными способностями
- 11 достижений для отслеживания прогресса
- Сохранение и загрузка игры (JSON)
- Прогресс-бары здоровья, еды и воды
- Интерактивные кнопки выбора в событиях

## Как играть

### Главное меню

При запуске открывается графическое меню с кнопками:
- **Новая игра** — начать новое прохождение
- **Загрузить игру** — продолжить сохранённую игру
- **Достижения** — просмотр полученных достижений
- **Выход** — закрыть игру

### 1. Выбор сложности

| Параметр | Лёгкая | Обычная | Сложная |
|----------|--------|---------|---------|
| Дней до победы | 10 | 7 | 5 |
| Расход еды в день | 1 | 1 | 2 |
| Расход воды в день | 1 | 2 | 3 |
| Стартовая еда | 15 | 10 | 5 |
| Стартовая вода | 15 | 10 | 5 |
| Макс. ресурс | 25 | 20 | 15 |
| Урон от голода | 10 | 20 | 30 |
| Урон от жажды | 10 | 20 | 30 |

### 2. Выбор класса

| Класс | Бонус |
|-------|-------|
| **Выживальщик** | Сбалансированный, без бонусов |
| **Медик** | +20 к макс. здоровью (120%), двойное лечение |
| **Разведчик** | Двойная добыча ресурсов |
| **Боец** | Половина урона от всех источников |

### 3. Игровой процесс

1. Открывается игровой экран с панелью статуса (здоровье, еда, вода, день, сложность, класс)
2. Происходит событие — текст с категорией и две кнопки выбора
3. Нажмите одну из кнопок, чтобы сделать выбор
4. Отобразится результат действия
5. Нажмите "Продолжить" для следующего дня
6. Цель — продержаться все дни (зависит от сложности)

## Установка и запуск

### Требования

- **Go 1.21+**
- **C компилятор** (GCC/MinGW) для CGO — требуется для сборки Fyne на Windows
  - Установите [MSYS2](https://www.msys2.org/) или [TDM-GCC](https://jmeubank.github.io/tdm-gcc/)
  - Убедитесь, что `gcc` доступен в PATH (`gcc --version`)

### Клонирование

```bash
git clone https://github.com/ВАШ_ЛОГИН/Бункер-3000.git
cd Бункер-3000
```

### Запуск

```bash
go run .
```

### Сборка

```bash
go build -o bunker3000.exe .
./bunker3000.exe
```

## Сохранение и загрузка

- Игра автоматически сохраняется после каждого дня в файл `bunker3000_save.json`
- Загрузка через кнопку "Загрузить игру" в главном меню
- Сохранение удаляется при завершении игры (победа/поражение)
- Формат: JSON (можно редактировать вручную)

## Тестирование

Проект покрыт unit-тестами.

```bash
# Все тесты
go test -v ./...

# Только тесты игрока
go test -v ./player

# Только тесты событий
go test -v ./events
```
