# Бункер-3000 — Симулятор выживания

[![Go Version](https://img.shields.io/badge/Go-1.20+-00ADD8?style=flat&logo=go)](https://go.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/Tests-23_Passing-brightgreen)](.)

Консольная игра-симулятор выживания в постапокалиптическом мире. Управляйте ресурсами, принимайте решения в случайных событиях и продержитесь до конца, несмотря на голод, жару, бандитов и дикую природу.

## Версия 2.0.0 — "Полная перезагрузка"

- 32 уникальных события с категориями (ресурсы, битвы, погода, опасности, помощь, находки)
- 4 уровня сложности с разными параметрами
- 4 класса персонажей с уникальными способностями
- 11 достижений для отслеживания прогресса
- Сохранение и загрузка игры (JSON)
- Цветной интерфейс с ANSI-подсветкой категорий событий
- Все эмодзи заменены на текстовые теги
- Главное меню (новая игра / загрузить / достижения / выход)

## Как играть

### Главное меню

При запуске открывается главное меню:

```
  1. Новая игра
  2. Загрузить игру
  3. Достижения и рекорды
  4. Выход
```

### 1. Выбор сложности

| Параметр | Лёгкая | Обычная | Сложная |
|----------|--------|---------|---------|
| Дней до победы | 10 | 7 | 5 |
| Расход еды в день | 1 | 1 | 2 |
| Расход воды в день | 1 | 2 | 3 |
| Стартовая еда | 15 | 10 | 5 |
| Стартовая вода | 15 | 10 | 5 |
| Макс. ресурс | 25 | 20 | 15 |
| Урон от голода | 10 | 20 | 30 |
| Урон от жажды | 10 | 20 | 30 |

### 2. Выбор класса

| Класс | Бонус |
|-------|-------|
| **Выживальщик** | Сбалансированный, без бонусов |
| **Медик** | +20 к макс. здоровью (120%), двойное лечение |
| **Разведчик** | Двойная добыча ресурсов |
| **Боец** | Половина урона от всех источников |

### 3. Игровой цикл

1. Начало дня — расход ресурсов (еда, вода)
2. Если ресурсов не хватает — потеря здоровья
3. Случайное событие с выбором из двух вариантов
4. Экран результата с описанием последствий
5. Текущий статус игрока
6. Нажмите Enter для следующего дня
7. Цель — продержаться все дни (зависит от сложности)

### Управление

- Ввод чисел в меню и при выборе варианта события
- Enter для продолжения после экранов

## Установка и запуск

### Клонирование

```bash
git clone https://github.com/ВАШ_ЛОГИН/Бункер-3000.git
cd Бункер-3000
```

### Запуск без сборки

```bash
go run .
```

### Сборка бинарного файла

```bash
go build -o bunker3000.exe .
./bunker3000.exe
```

## Сохранение и загрузка

- Игра автоматически сохраняется после каждого дня в файл `bunker3000_save.json`
- Загрузка через пункт меню "Загрузить игру"
- Сохранение удаляется при завершении игры (победа/поражение)
- Формат: JSON (можно редактировать вручную)

## Тестирование

Проект покрыт unit-тестами.

```bash
# Все тесты
go test -v ./...

# Только тесты игрока
go test -v ./player

# Только тесты событий
go test -v ./events
```
